# ModernFix-mVUS
ModernFix-mVUS is a fork of ModernFix that will release Modernfix versions for any version that is not supported by the official mod. When the official mod updates to a specific minecraft version this fork will skip releasing that version.

## Downloads:
- https://modrinth.com/mod/modernfix-mvus
- https://www.curseforge.com/minecraft/mc-mods/modernfix-mvus

## Version Support
- ModernFix-mVUS will ONLY fix issues for the currently supported Minecraft versions, i.e:
    - Versions which have the latest build versions.
        - A few exceptions are when a latest release drops, mVUS might still release a build for the previous release or the release for the latest version has the same build version as the previous one.
        - For example 26.2 dropped on 16th June, 2026 but the latest build (at 17/06/26) 5.27.17 was released for 26.1 and 26.2.
        - In the above case as 26.1 is speculated to be the next "LTS" version for modpacks, it will be supported for a considerable amount of time but that might not be the case with 26.2 and when 26.3 is released, the support for 26.2 might be dropped while 26.1 still stays supported.
